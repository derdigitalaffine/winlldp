# WinLLDP

Windows-LLDP-Anwendung in der Anforderungsphase.

Bestätigt sind die Anzeige von Switch und Port, ein optionaler LLDP-Sendebetrieb innerhalb der Anwendung ohne Windows-Dienst sowie die Auslieferung als portable EXE und Installationspaket.

## Arbeitsgrundlage
- [Agentenorganisation](AGENTS.md)
- [Bestätigte Anforderungen und offene Fragen](docs/PRODUCT_SPEC.md)

Die Arbeitsorganisation stammt strukturell aus [kostuemwettbewerb](https://github.com/derdigitalaffine/kostuemwettbewerb/blob/c9e99775decb2b35af8def14ae366c3fe69d6d00/AGENTS.md) und ist an dieses Projekt angepasst.

## Build
Ziel sind echte, kompilierte Release-Artefakte unter build/ im Repository.
Aktuell gibt es noch keinen Anwendungscode und keinen Build. Technik und Funktionsumfang werden mit dem Nutzer geklärt.
